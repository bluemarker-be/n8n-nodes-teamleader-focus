# @bluemarker/n8n-nodes-teamleader-focus

n8n community node for the [Teamleader Focus](https://focus.teamleader.eu) CRM and invoicing API.

## Install

In n8n:

1. Go to **Settings → Community Nodes**
2. Enter `@bluemarker/n8n-nodes-teamleader-focus`
3. Install and reload

## Setup

1. Create a Teamleader Focus OAuth2 application at https://marketplace.teamleader.eu
2. In n8n, create a **Teamleader Focus OAuth2 API** credential and enter your client ID/secret
3. Complete the OAuth flow

## Features

The node covers a broad slice of the Teamleader Focus API — contacts, companies, deals, invoices, quotations, meetings, tasks, projects, tickets, and more. See [CHANGELOG.md](./CHANGELOG.md) for the current scope per release.

Includes a webhook trigger for real-time event handling.
